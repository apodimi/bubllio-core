# Bubllio Core 0.1.0-alpha.3

Internal technical alpha for controlled installation testing with synthetic
accounts and data.

## Fixes and verification

- The non-root realm importer can traverse its import directory (`0755`) while
  the bundled realm JSON remains read-only (`0444`).
- Bootstrap waits for vault initialization and mounts the vault read-only.
- CI tests the actual production image, fresh database initialization, realm
  import, readiness, machine identities, and a redeploy without the raw setup
  secret. Redeploy must preserve credential and setup-proof fingerprints.
- The published Keycloak digest must pass the same checks before a GitHub
  prerelease is created.

Use the current repository's `deploy/managed/compose.yaml` after its reviewed
release promotion for Git-based deployment. The release-generated Compose asset
also selects this release's immutable image digests. The installation contract
remains independent of the hosting panel: provide the base domain, one setup
secret, and the existing reverse-proxy network.

Version `0.1.0-alpha.2` has a confirmed fresh-import permission defect. Do not
use that version for new installations. Existing installation data and secrets
must be preserved when applying this correction; no reset is required.

## Remaining gates

A full public-host browser rehearsal, external SMTP/privacy/abuse decisions,
setup recovery, backup/restore, monitoring, upgrade/rollback, complete member
administration, CRM adoption, and release signing remain open. Passing the
container tests does not establish Production readiness or certify all hosting
platforms.
